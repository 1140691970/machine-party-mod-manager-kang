# 安全说明

[English](../../SECURITY.md) · **简体中文** · [繁體中文](../zh-TW/SECURITY.md)

## 支持的版本

只有稳定更新通道上的最新版本会收到安全修复。已安装的客户端可在设置页或启动提示中自动更新。

## 报告漏洞

请不要为安全问题开公开 Issue，请通过 [GitHub 安全公告](https://github.com/JamesGZM/machine-party-mod-manager/security/advisories/new)私下报告。

请说明受影响的版本与平台、复现步骤、观察到的影响以及可能的修复建议。不要附上真实凭据或其他玩家的数据。维护者看到后会尽快回复；公开披露前请预留修复与发布签名版本的时间。

## 范围

属于范围内：

- 桌面 App，包括 IPC 命令、对游戏目录与配置文件的处理，以及签名更新链路。
- `services/update-worker` 中的更新 Worker 与发布工作流。
- 任何可能让 App 安装未签名构建或未经校验的模组包、写入所选游戏副本之外的位置、或打开任意网址的问题。

不在范围内：游戏本身或第三方模组的漏洞（请报告给其作者），以及需要机器已被攻破才能利用的问题。
