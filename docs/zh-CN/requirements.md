# 产品需求

[English](../en/requirements.md) · **简体中文** · [繁體中文](../zh-TW/requirements.md)

## 首页与搜索

首页直接呈现团队已验证并发布的目录。每个项目提供名称、作者、用途、作者项目主页、适用游戏版本、可安装版本、本机状态与主要操作。上游有新版时，只有通过团队验证的版本可供安装。

- 搜索在本机匹配简中、繁中与英文模组名称，输入部分名称即可，英文忽略大小写。清空搜索即显示完整目录。无结果时显示“找不到已收录的模组”。
- 排序只取决于固定收录序号。搜索、更新、改名与 Stars 变化都保持相对顺序。最新还是最早收录在前，待首页定稿时决定。
- 产品不提供筛选、排行榜或 GitHub 全站搜索。模组资料来自 GitHub，收录、兼容性与安装版本由团队决定。
- App、搜索、安装与卸载免费。模组详情提供作者入口，玩家可以选择查看原始说明。

## 第一次打开

找到唯一有效的 Steam 游戏副本时直接显示可用操作。找不到游戏时仍可浏览，并在安装位置显示“选择游戏目录”。找到多份时显示候选路径供选择。设置页提供当前路径、重新检测与手动选择，并记住玩家有效的手动选择。

## 一键管理

在 Windows 上，安装、更新、切换或卸载模组时，管理器会检查所选游戏副本是否在运行。保存进度后可选择 **关闭游戏并继续**。如果游戏仍未退出，可以继续等待、取消或手动确认强制结束。

| 玩家操作或情境 | 可观察的结果 |
| --- | --- |
| 点击“安装” | App 下载指定版本、校验、备份并安装。显示进度，验证成功后显示已安装版本。 |
| 点击“卸载” | App 根据本机记录移除模组并验证结果。保留其他模组需要的文件、共用加载器及玩家原有数据。 |
| 点击“切换” | 明确提示将被替换的互斥模组。先备好新包，再还原旧模式并安装。显示实际生效状态。 |
| 游戏运行中或数据不符 | 提示关闭游戏后重试，或显示不兼容的版本、未知修改。完成识别前暂停写入。 |
| 网络中断或模组下架 | 可浏览与搜索已缓存的目录，并离线卸载先前由 App 安装的模组。首次离线启动应提示目录尚未下载。 |

## 首版验收

1. Steam 装在非系统盘仍能检测到；手动选择在重启后保留，原路径失效时才重新检测。
2. 玩家只操作 App 即可安装已验证的 Overtime；从 Steam 进入游戏能看到对应版本并完成一局。
3. 断网后点一次卸载，原版 PCK 的 SHA-256 与安装前一致，可以再次启动原版。
4. 模拟下载失败、写入中断与 Steam 更新。重新打开后显示实际状态，避免旧备份覆盖新版游戏。
5. 搜索命中部分名称时仍按收录序号呈现。打开作者主页与安装是两个独立操作。
6. 中国大陆玩家在无代理、无 App 缓存且无法连接 GitHub 时，能经正式 Worker 获取目录。同步过的玩家断网后可搜索缓存；首次离线时提供重试与本机已安装入口。按[三网验收方案](catalog/delivery.md)分别验证列表与安装包下载。
