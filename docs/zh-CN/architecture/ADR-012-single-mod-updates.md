# ADR-012 · 更新单个已安装模组

[English](../../en/architecture/ADR-012-single-mod-updates.md) · **简体中文** · [繁體中文](../../zh-TW/architecture/ADR-012-single-mod-updates.md)

已安装模组有更新的获准版本时，玩家可以单独更新该模组。管理器逐段比较数字版本号，Rust 后端根据安装交易识别游戏副本和模组。

目录部署流程会将 `machine-party-mod-catalog-v1\n` 加在完整 UTF-8 目录前，再使用发布密钥签名。只有完整目录带有签名。对于管理器已识别的原生 MPML 模组，后端会核对签名、模组 ID、作者仓库、内置适配器配置、包大小和 SHA-256。正式版只接受已验证的版本，Windows 测试版也接受明确标为测试的模组版本。内置包沿用原有授权。需要转换的模组发布新版时，管理器须先内置对应的转换规则。

先卸载再安装可能移除共享加载器，或因下载失败而失去旧版。单模组更新会在游戏所在磁盘准备已验证的新版、核对旧文件、记录两组指纹，再替换选中的模组目录。写入新交易是提交点，中断发生在提交前会恢复旧版，提交后会保留已验证的新版。若游戏运行中或文件存在未知修改，管理器会保留恢复记录供下次扫描处理。

发行包测试在同一份合成游戏副本安装滚筒嘉年华 v0.1.0 和 Lobby Bots v0.1.4，再将滚筒更新至 v0.1.1。测试核对失败回退、重启恢复、共存模组的文件与交易、共享加载器与 PCK 指纹，以及离线卸载。Windows Steam 游戏内验收仍待完成。
