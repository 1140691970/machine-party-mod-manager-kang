# ADR-008 · 下载缓存、启动检测与还原校验

[English](../../en/architecture/ADR-008-cached-installations.md) · **简体中文** · [繁體中文](../../zh-TW/architecture/ADR-008-cached-installations.md)

重新打开管理器时，读取 PCK 的延迟可能让已安装的模组暂时显示为未安装。残留还原文件也可能被误认为手动安装。每个目录版本独立缓存下载。Rust 从随包目录解析安装参数，使用前重新校验 ZIP，写入前再次确认所选副本。

启动先显示已有记录，根据相关文件的标识、大小和修改时间复用显示状态。副本变化或手动重新检查时才完整读取一次 PCK。发现疑似手动安装时，使用相符的缓存包运行上游只读状态检查；接管还需要在临时副本试还原成功。原版 PCK 旁有未知还原文件时提示残留。

新安装保留经过校验的完整备份。卸载完成需要原版 PCK 指纹相符，且本次创建的附属文件已清除。启动检测保留备份，清除下载也保留每个副本的还原数据。继续读取已有安装记录、路径及旧版差量交易。每次启动计算完整哈希会增加磁盘读取，仅凭文件属性也不足以授权写入。

Rust 测试覆盖再次启动、强制检查、残留文件、外部修改和操作中断。Windows 测试版仍需在玩家的 Steam 副本上验证游戏和离线还原。
