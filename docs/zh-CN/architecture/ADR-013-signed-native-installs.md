# ADR-013 · 从签名目录安装原生模组

[English](../../en/architecture/ADR-013-signed-native-installs.md) · **简体中文** · [繁體中文](../../zh-TW/architecture/ADR-013-signed-native-installs.md)

旧测试版能显示新模组，安装却需要再发一版管理器。现在第一方新模组可通过签名目录加入：核对作者仓库、按 ID 记录安装及内置加载器适配规则。适配规则仅允许变更包内文件清单。测试版接受测试频道，正式版需要已验证条目。转包模组沿用内置转换规则。

首次安装、更新及扫描使用同一份授权数据。管理器保存新 ID 的首份签名说明，再次验签后可用于离线扫描及卸载。线上包的安装仍须符合当前授权。原有安装记录及备份继续适用。

在“已安装”按“检查模组更新”。有兼容新版时会显示“更新至”；点击后可核对旧版、新版和游戏位置。按“确认更新”后才开始下载。目录测试覆盖新 ID 及不兼容适配规则，事务测试覆盖更新及还原。
