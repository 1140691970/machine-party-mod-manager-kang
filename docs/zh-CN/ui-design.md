# 界面设计规范

[English](../en/ui-design.md) · **简体中文** · [繁體中文](../zh-TW/ui-design.md)

本文描述桌面端当前的界面规格，并标出尚未实现的部分。参考图为 [ui-reference.png](../images/ui-reference.png)。界面改版会直接更新本文，不追加“取代上文”的段落。

## 视觉基调

- 暗黑工业风，贴近 Machine Party 的游戏氛围。背景为深炭灰层次：侧边栏深于主内容区，卡片用细边框区分。
- 主要操作按钮为暖米白底（约 `#E6E1CC`）配深色文字；次要操作为深色描边按钮；错误文字用暖橙色。
- 品牌字使用 Impact 类窄体粗字；正文使用系统 UI 字体（Segoe UI、Microsoft YaHei、PingFang SC）。
- 所有可聚焦元素有明显的焦点框，支持键盘操作。

## 布局

- **左侧导航栏**：顶部是品牌 `MACHINE PARTY` 与副标题“模组管理器”。主导航为“模组目录”“已安装”，每项高度至少 44px，间距 6px。底部为“设置”。
- **标题区**：左侧为页面标题与副标题，模组目录页右侧为搜索框，提示文字“搜索模组、作者或关键字”。
- **内容区**：等高卡片网格，按可用宽度自动排列，单卡最小宽度约 282px。
- **窄窗口（≤760px）**：侧边栏收起为图标栏，标题区改为上下排列，搜索框占满宽度。

## 模组卡片

1. **封面（16:9）**：左上角显示目录版本（无版本时显示“版本未收录”），右上角显示状态标签。图片加载失败时显示带模组名称的标题封面，不在图片上叠加文字。
2. **标题与简介**：标题是可点击的链接，打开详情。下方为一句话简介，说明核心用途与联机前提。若本机有管理器安装记录，再显示“本机 · 版本”与“目录 · 版本”。
3. **底部操作**：一个全宽按钮。作者主页入口放在详情中，不放在卡片上。

| 本机与目录比较 | 状态标签 | 主按钮 |
| --- | --- | --- |
| 没有安装记录 | “待验证”（目录版本未验证时） | “安装”（未验证时提示等待实机验证） |
| 版本相同 | “与目录版本一致” | “卸载” |
| 本机较旧，新版待验证 | “新版待验证”，保留现有安装 | “更新”（提示新版通过验证后才可更新） |
| 本机较旧，新版已验证 | “有更新” | “更新” |
| 本机较新 | “本机版本较新”，保留现有安装 | “卸载” |
| 任一版本未知、格式无法比较，或安装记录读取失败 | “需核对版本”，不自动替换 | “需核对版本”（打开详情） |

安装引擎接入前，安装、更新与卸载按钮只弹出说明，不修改任何文件。

## 详情弹窗

依次显示：详细说明（联机条件、所需加载器、互斥关系）、目录版本、本机版本与状态说明（如有），以及作者主页入口（`作者 ↗`）。之后将补充原版多人能力差异与上游授权信息。

## 设置页

- 界面语言：简体中文、繁體中文、English。首次按系统语言选择，用户选择会被记住。
- 游戏目录：显示当前路径或“尚未选择游戏目录”，提供“选择游戏目录”和“重新检测”。
- 管理器版本与“检查应用更新”。发现新版时，主内容区顶部出现更新按钮，点击后确认“更新并重启”并显示下载进度。

## 首次启动

找到唯一游戏副本时直接载入；找到多份时弹窗列出候选路径；找不到时提示选择目录或先浏览，可以“稍后设置”。

## 规划中

- 侧边栏底部的游戏状态行：绿点加“游戏版本 v2.1.2”；未检测到游戏时改为警示色，点击选择目录。
- “切换”按钮：与当前生效模组互斥时显示，确认弹窗说明将替换的模组，先备好新包再还原旧模组。
- 安装、切换与更新的确认弹窗：检查游戏运行状态、版本指纹与互斥关系，不兼容或存在未知修改时中断并说明下一步；执行时依次显示下载、校验、应用、验证，成功后才写入新的安装记录。
- 下一轮界面重设计：建立设计 token（颜色、间距、字号、圆角）、组件分层与统一的图标体系，替换目前的字符图标。
