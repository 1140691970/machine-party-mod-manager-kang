# 界面设计规范

[English](../en/ui-design.md) · **简体中文** · [繁體中文](../zh-TW/ui-design.md)

本文描述桌面端当前的界面规格，并标出尚未实现的部分。当前界面见[截图](../images/screenshot-catalog.png)，最初的概念图为 [ui-reference.png](../images/ui-reference.png)。界面改版会直接更新本文，不追加“取代上文”的段落。

## 视觉风格：机械派对

取自游戏里的酒红工服与黄铜机械：暗酒红底色、黄铜金强调、奶油白文字，圆角与立体按钮带一点游戏感，但不喧宾夺主，模组封面始终是视觉重心。

- **品牌**：齿轮工牌标识，即黄铜齿轮里嵌一张奶油色面罩脸，放在酒红圆角底上。界面使用 `apps/desktop/ui/images/logo.svg`；应用图标的源文件是 `apps/desktop/artwork/app-icon.svg`（带 macOS 留白），在 `apps/desktop/src-tauri` 中运行 `npx --yes --package @tauri-apps/cli@2.12.5 tauri icon ../artwork/app-icon.svg -o /tmp/icons` 后，只把桌面端用到的尺寸复制进 `icons/`。
- **设计 token**：颜色、字体、字号、间距、圆角、阴影与动效全部定义在 `apps/desktop/ui/tokens.css`。组件与布局只引用变量，不写新的色值。
  - 底色由深到浅：侧边栏 `--wine-900`、主区 `--wine-850`、卡片 `--wine-800`、悬停 `--wine-750`；选中导航为 `--wine-600`。
  - 强调色为黄铜 `--brass-500`，用于主按钮、链接与“有更新”标签；成功为浅绿，警示为暖橙。
  - 标题与品牌使用窄体粗字（Avenir Next Condensed / Bahnschrift Condensed），正文使用系统 UI 字体，版本号使用等宽字体。
- **通用组件**（`components.css`，由 `dom.js` 与 `icons.js` 创建）：
  - 按钮 `button(text, action, variant, icon)`：`primary` 黄铜立体按钮、`secondary` 描边按钮、`ghost` 无底按钮、`link` 文字链接；卡片主按钮加 `btn-block` 占满宽度。
  - 标签 `tag(text, tone)`：深色胶囊，`accent`、`success`、`warning` 三种语气；版本号标签使用等宽字体。
  - 卡片 `.card`、面板 `.panel`、输入框 `.field`、分段切换 `.segmented` / `.segment`、弹窗 `.dialog`（含更新说明 `.release-notes`）、提示红点 `.update-dot`、进度条 `progress()`、骨架屏 `.skeleton`。
  - 弹窗中的按钮自动归入底部操作行；文字链接留在正文中。
  - 图标为 24px 线性图标，颜色跟随文字，由 `icon(name)` 生成，替代此前的字符图标。
- **动效**：卡片在切换页面时依次上浮淡入（搜索时不重播），悬停时上浮并显示黄铜描边、封面轻微放大；按钮按下下沉 1px；弹窗弹性缩放淡入；封面加载前显示骨架屏闪光；品牌标识悬停时轻微转动。系统开启“减少动态效果”时，所有时长归零。
- 所有可聚焦元素有明显的黄铜焦点框，支持键盘操作。

## 布局

- **左侧导航栏**：顶部是标识与 `MACHINE PARTY`、副标题“模组管理器”。主导航为“模组目录”“已安装”，每项带图标、高度至少 44px，选中项为酒红底加黄铜图标。底部为“设置”，发现新版管理器时显示红色小圆点 `.update-dot`。
- **标题区**：左侧为窄体页面标题与副标题，模组目录页右侧为胶囊搜索框，提示文字“搜索模组、作者或关键字”。
- **内容区**：等高卡片网格，按可用宽度自动排列，单卡最小宽度约 280px。设置页为纵向面板列表，最大宽度 720px。
- **窄窗口（≤760px）**：侧边栏收起为只显示标识与图标的窄栏，标题区改为上下排列，搜索框占满宽度。

## 模组卡片

1. **封面（16:9）**：左上角显示目录版本（无版本时显示“版本未收录”），右上角显示状态标签：Windows 测试版条目未正式定版前显示“测试版”（`isPreview`），“有更新”为黄铜底，“与目录版本一致”为绿色字，“本机版本较新”“需核对版本”为暖橙字，其余为默认深色标签。图片加载前显示骨架屏；没有图片或加载失败时显示酒红渐变的标题封面，不在图片上叠加文字。
2. **标题与简介**：标题是可点击的链接，打开详情。下方为一句话简介，说明核心用途与联机前提，以及“支持游戏版本 · v2.1.2”（或“支持版本待确认”）。若本机有管理器安装记录，再显示“本机 · 版本”与“目录 · 版本”。
3. **底部操作**：一个全宽按钮。作者主页入口放在详情中，不放在卡片上。

| 本机与目录比较 | 状态标签 | 主按钮 |
| --- | --- | --- |
| 没有安装记录 | “待验证” / “测试版”（未验证 / Windows 测试版） | “安装”（Windows 测试版进入分步安装弹窗，未验证则提示等待实机验证） |
| 版本相同 | “与目录版本一致” | “卸载” |
| 本机较旧，新版待验证 | “新版待验证”，保留现有安装 | “更新”（提示新版通过验证后才可更新） |
| 本机较旧，新版已验证 | “有更新” | “更新” |
| 本机较新 | “本机版本较新”，保留现有安装 | “卸载” |
| 任一版本未知、格式无法比较，或安装记录读取失败 | “需核对版本”，不自动替换 | “需核对版本”（打开详情） |

在 Windows 测试版中，全部五个 `v2.1.2` 目录条目都会执行真实的分步安装与卸载弹窗（下载、复用缓存，或直接从应用内释放 `"bundled": true` 内置自研模组而无需下载；随后完成校验、备份、安装/还原、回读验证、失败重试以及互斥冲突提示）；在 macOS 上或面对未验证版本时，操作仅说明状态，不修改任何游戏文件。

## 详情弹窗

依次显示：详细说明（联机条件、所需加载器、互斥关系）、支持游戏版本、目录版本、本机版本与状态说明（如有）、清理缓存按钮（已缓存时）、安装包下载链接（允许镜像时），以及带外链图标的作者主页入口。

## 设置页

设置页由三块面板组成：

- **界面语言**：三段式 `.segmented` 切换控件（`简体中文` · `繁體中文` · `English`）。首次按系统语言选择，用户选择保存在 `localStorage`。
- **游戏目录**：标题行旁在校验通过时显示紧凑的 `v2.1.2` 版本标签，下方以等宽字体只显示已保存的游戏根路径（不展示 `Machine Party_Windows` 等子目录），右侧对齐“选择游戏目录”与“重新检测”按钮。重新检测若找到 0 份或多份副本，会保留现有有效目录；不再显示冗余的“重新校验文件”按钮。
- **管理器与更新**：合并为单行，左侧为带下划线的 `Machine Party 模组管理器` 链接（经 `open_project` 打开 GitHub 仓库），右侧为版本号按钮并在启动时自动静默检查更新，有新版时显示红点 `.update-dot`。顶部不设更新横幅按钮；发现新版后每个版本号自动弹出一次非强制更新弹窗（若当前已有弹窗则顺延队列，点击“稍后再说”或关闭弹窗后将版本号记入 `localStorage`，也可随时点击设置页版本号手动重开），展示 `notes` 更新说明或默认提示，支持“更新并重启”与百分比进度条。

## 首次启动

找到唯一游戏副本时直接载入；找到多份时弹窗列出候选路径；找不到时提示选择目录或先浏览，可以“稍后设置”。

## 规划中

- 侧边栏底部的游戏状态行：绿点加“游戏版本 v2.1.2”；未检测到游戏时改为警示色，点击选择目录。
- 互斥模组的一键“切换”按钮：确认弹窗说明将被替换的模组，先备妥新包再还原旧模组并安装新模组。
