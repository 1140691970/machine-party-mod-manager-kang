# 更新紀錄

[English](../../CHANGELOG.md) · [简体中文](../zh-CN/CHANGELOG.md) · **繁體中文**

記錄對玩家與貢獻者有影響的變化。版本號與桌面 App 一致。

## 0.1.2-2 — 2026-11-19

Windows 測試版可在指定的 v2.1.2 遊戲副本上測試 Overtime v1.7。點一次「安裝」，彈窗會自動下載、校驗並安裝；已有快取可直接離線安裝。操作前請完全退出遊戲。其他模組取得對應版本的依據前會顯示「支援版本待確認」。

## 0.1.2-1 — 2026-11-19

Windows x64 測試版可用來檢查新版介面、線上模組目錄、遊戲目錄偵測和各副本的狀態。此測試版開放隨包 Overtime v1.7 的 Windows 安裝與離線還原，供實機驗證。

### 變更

- 倉庫重組為 `apps/desktop`、`services/update-worker` 與 `catalog`。模組清單改由唯一的 `catalog/mods.json` 提供。玩家看不到任何變化。
- 文件提供英文、簡體中文與繁體中文版本，並加入架構決策紀錄。

### 新增

- 貢獻指南、安全與支援說明、Issue 與 PR 範本，以及每次推送都執行的原始碼檢查。

## 0.1.1 — 2026-11-18

### 新增

- Apple Silicon Mac 版本，與 Windows 共用穩定通道的簽章應用程式內更新。

## 0.1.0 — 2026-11-18

### 新增

- 首個原型：隨包發布四個候選模組的目錄，支援三語搜尋、詳情與作者連結。
- Steam 遊戲偵測、手動選擇目錄與按副本比較版本。
- Windows x64 的簽章應用程式內更新，經專案的更新 Worker 提供。
