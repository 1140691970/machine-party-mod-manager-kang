# 安全說明

[English](../../SECURITY.md) · [简体中文](../zh-CN/SECURITY.md) · **繁體中文**

## 支援的版本

只有穩定更新通道上的最新版本會收到安全修正。已安裝的客戶端可在設定頁或啟動提示中自動更新。

## 回報漏洞

請勿為安全問題開公開 Issue，請透過 [GitHub 安全公告](https://github.com/JamesGZM/machine-party-mod-manager/security/advisories/new)私下回報。

請說明受影響的版本與平台、重現步驟、觀察到的影響以及可能的修正建議。不要附上真實憑證或其他玩家的資料。維護者看到後會盡快回覆；公開揭露前請預留修正與發布簽章版本的時間。

## 範圍

屬於範圍內：

- 桌面 App，包括 IPC 命令、對遊戲目錄與設定檔的處理，以及簽章更新鏈路。
- `services/update-worker` 中的更新 Worker 與發布工作流程。
- 任何可能讓 App 安裝未簽章建置或未經校驗的模組套件、寫入所選遊戲副本以外的位置、或開啟任意網址的問題。

不在範圍內：遊戲本身或第三方模組的漏洞（請回報給其作者），以及需要機器已遭入侵才能利用的問題。
