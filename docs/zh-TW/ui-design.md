# 介面設計規範

[English](../en/ui-design.md) · [简体中文](../zh-CN/ui-design.md) · **繁體中文**

本文描述桌面端目前的介面規格，並標出尚未實作的部分。參考圖為 [ui-reference.png](../images/ui-reference.png)。介面改版會直接更新本文，不追加「取代上文」的段落。

## 視覺基調

- 暗黑工業風，貼近 Machine Party 的遊戲氛圍。背景為深炭灰層次：側邊欄深於主內容區，卡片以細邊框區隔。
- 主要操作按鈕為暖米白底（約 `#E6E1CC`）配深色文字；次要操作為深色外框按鈕；錯誤文字使用暖橙色。
- 品牌字使用 Impact 類窄體粗字；內文使用系統 UI 字型（Segoe UI、Microsoft YaHei、PingFang SC）。
- 所有可聚焦元素有明顯的焦點框，支援鍵盤操作。

## 版面

- **左側導覽欄**：頂部為品牌 `MACHINE PARTY` 與副標「模組管理器」。主導覽為「模組目錄」「已安裝」，每項高度至少 44px，間距 6px。底部為「設定」。
- **標題區**：左側為頁面標題與副標，模組目錄頁右側為搜尋框，提示文字「搜尋模組、作者或關鍵字」。
- **內容區**：等高卡片網格，依可用寬度自動排列，單卡最小寬度約 282px。
- **窄視窗（≤760px）**：側邊欄收合為圖示欄，標題區改為上下排列，搜尋框佔滿寬度。

## 模組卡片

1. **封面（16:9）**：左上角顯示目錄版本（無版本時顯示「版本未收錄」），右上角顯示狀態標籤。圖片載入失敗時顯示帶模組名稱的標題封面，不在圖片上疊加文字。
2. **標題與簡介**：標題是可點擊的連結，開啟詳情。下方為一句話簡介，說明核心用途與連線前提。若本機有管理器安裝紀錄，再顯示「本機 · 版本」與「目錄 · 版本」。
3. **底部操作**：一個全寬按鈕。作者首頁入口放在詳情中，不放在卡片上。

| 本機與目錄比較 | 狀態標籤 | 主按鈕 |
| --- | --- | --- |
| 沒有安裝紀錄 | 「待驗證」（目錄版本未驗證時） | 「安裝」（未驗證時提示等待實機驗證） |
| 版本相同 | 「與目錄版本一致」 | 「解除安裝」 |
| 本機較舊，新版待驗證 | 「新版待驗證」，保留現有安裝 | 「更新」（提示新版通過驗證後才可更新） |
| 本機較舊，新版已驗證 | 「有更新」 | 「更新」 |
| 本機較新 | 「本機版本較新」，保留現有安裝 | 「解除安裝」 |
| 任一版本不明、格式無法比較，或安裝紀錄讀取失敗 | 「需核對版本」，不自動替換 | 「需核對版本」（開啟詳情） |

安裝引擎接入前，安裝、更新與解除安裝按鈕只彈出說明，不修改任何檔案。

## 詳情彈窗

依序顯示：詳細說明（連線條件、所需載入器、互斥關係）、目錄版本、本機版本與狀態說明（如有），以及作者首頁入口（`作者 ↗`）。之後將補充原版多人能力差異與上游授權資訊。

## 設定頁

- 介面語言：简体中文、繁體中文、English。初次依系統語系選擇，使用者選擇會被保留。
- 遊戲目錄：顯示目前路徑或「尚未選擇遊戲目錄」，提供「選擇遊戲目錄」與「重新偵測」。
- 管理器版本與「檢查應用程式更新」。發現新版時，主內容區頂部出現更新按鈕，點擊後確認「更新並重新啟動」並顯示下載進度。

## 首次啟動

找到唯一遊戲副本時直接載入；找到多份時彈窗列出候選路徑；找不到時提示選擇目錄或先瀏覽，可「稍後設定」。

## 規劃中

- 側邊欄底部的遊戲狀態列：綠點加「遊戲版本 v2.1.2」；未偵測到遊戲時改為警示色，點擊選擇目錄。
- 「切換」按鈕：與目前生效模組互斥時顯示，確認彈窗說明將取代的模組，先備妥新套件再還原舊模組。
- 安裝、切換與更新的確認彈窗：檢查遊戲執行狀態、版本指紋與互斥關係，不相容或存在未知修改時中斷並說明下一步；執行時依序顯示下載、校驗、套用、驗證，成功後才寫入新的安裝紀錄。
- 下一輪介面重新設計：建立設計 token（顏色、間距、字級、圓角）、元件分層與統一的圖示體系，取代目前的字元圖示。
