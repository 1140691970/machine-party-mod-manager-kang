# 介面設計規範

[English](../en/ui-design.md) · [简体中文](../zh-CN/ui-design.md) · **繁體中文**

本文描述桌面端目前的介面規格，並標出尚未實作的部分。目前介面見[截圖](../images/screenshot-catalog.zh-TW.png)，最初的概念圖為 [ui-reference.png](../images/ui-reference.png)。介面改版會直接更新本文，不追加「取代上文」的段落。

## 視覺風格：機械派對

取自遊戲裡的酒紅工作服與黃銅機械：暗酒紅底色、黃銅金強調、奶油白文字，圓角與立體按鈕帶一點遊戲感，但不喧賓奪主，模組封面始終是視覺重心。

- **品牌**：齒輪工牌標誌，即黃銅齒輪裡嵌一張奶油色面罩臉，置於酒紅圓角底上。介面使用 `apps/desktop/ui/images/logo.svg`；應用程式圖示的原始檔是 `apps/desktop/artwork/app-icon.svg`（含 macOS 留白），在 `apps/desktop/src-tauri` 中執行 `npx --yes --package @tauri-apps/cli@2.12.5 tauri icon ../artwork/app-icon.svg -o /tmp/icons` 後，只把桌面端用到的尺寸複製進 `icons/`。
- **設計 token**：顏色、字型、字級、間距、圓角、陰影與動效全部定義在 `apps/desktop/ui/tokens.css`。元件與版面只引用變數，不寫新的色值。
  - 底色由深到淺：側邊欄 `--wine-900`、主區 `--wine-850`、卡片 `--wine-800`、懸停 `--wine-750`；選中的導覽項為 `--wine-600`。
  - 強調色為黃銅 `--brass-500`，用於主按鈕、連結與「有更新」標籤；成功為淺綠，警示為暖橙。
  - 標題與品牌使用窄體粗字（Avenir Next Condensed / Bahnschrift Condensed），內文使用系統 UI 字型，版本號使用等寬字型。
- **共用元件**（`components.css`，由 `dom.js` 與 `icons.js` 建立）：
  - 按鈕 `button(text, action, variant, icon)`：`primary` 黃銅立體按鈕、`secondary` 外框按鈕、`ghost` 無底按鈕、`link` 文字連結；卡片主按鈕加上 `btn-block` 佔滿寬度。
  - 標籤 `tag(text, tone)`：深色膠囊，`accent`、`success`、`warning` 三種語氣；版本號標籤使用等寬字型。
  - 卡片 `.card`、面板 `.panel`、輸入框 `.field`、分段切換 `.segmented` / `.segment`、彈窗 `.dialog`（含更新說明 `.release-notes`）、提示紅點 `.update-dot`、進度條 `progress()`、骨架畫面 `.skeleton`。
  - 彈窗中的按鈕自動歸入底部操作列；文字連結留在內文。
  - 圖示為 24px 線性圖示，顏色跟隨文字，由 `icon(name)` 產生，取代先前的字元圖示。
- **動效**：切換頁面時卡片依序上浮淡入（搜尋時不重播），懸停時上浮並顯示黃銅外框、封面輕微放大；按鈕按下時下沉 1px；彈窗以彈性縮放淡入；封面載入前顯示骨架畫面閃光；品牌標誌懸停時輕微轉動。系統開啟「減少動態效果」時，所有時長歸零。
- 所有可聚焦元素有明顯的黃銅焦點框，支援鍵盤操作。

## 版面

- **左側導覽欄**：頂部為標誌與 `MACHINE PARTY`、副標「模組管理器」。主導覽為「模組目錄」「已安裝」，每項帶圖示、高度至少 44px，選中項為酒紅底加黃銅圖示。底部為「設定」，發現新版管理器時顯示紅色小圓點 `.update-dot`。
- **標題區**：左側為窄體頁面標題與副標，模組目錄頁右側為膠囊搜尋框，提示文字「搜尋模組、作者或關鍵字」。
- **內容區**：等高卡片網格，依可用寬度自動排列，單卡最小寬度約 280px。設定頁為縱向面板列表，最大寬度 720px。
- **窄視窗（≤760px）**：側邊欄收合為只顯示標誌與圖示的窄欄，標題區改為上下排列，搜尋框佔滿寬度。

## 模組卡片

1. **封面（16:9）**：左上角顯示目錄版本（無版本時顯示「版本未收錄」），右上角顯示狀態標籤：Windows 測試版條目未正式定版前顯示「測試版」（`isPreview`），「有更新」為黃銅底，「與目錄版本一致」為綠色字，「本機版本較新」「需核對版本」為暖橙字，其餘為預設深色標籤。圖片載入前顯示骨架畫面；沒有圖片或載入失敗時顯示酒紅漸層的標題封面，不在圖片上疊加文字。
2. **標題與簡介**：標題是可點擊的連結，開啟詳情。下方為一句話簡介，說明核心用途與連線前提，以及「支援遊戲版本 · v2.1.2」（或「支援版本待確認」）。若本機有管理器安裝紀錄，再顯示「本機 · 版本」與「目錄 · 版本」。
3. **底部操作**：一個全寬按鈕。作者首頁入口放在詳情中，不放在卡片上。

| 本機與目錄比較 | 狀態標籤 | 主按鈕 |
| --- | --- | --- |
| 沒有安裝紀錄 | 「待驗證」 / 「測試版」（未驗證 / Windows 測試版） | 「安裝」（Windows 測試版進入分步安裝彈窗，未驗證則提示等待實機驗證） |
| 版本相同 | 「與目錄版本一致」 | 「解除安裝」 |
| 本機較舊，新版待驗證 | 「新版待驗證」，保留現有安裝 | 「更新」（提示新版通過驗證後才可更新） |
| 本機較舊，新版已驗證 | 「有更新」 | 「更新」 |
| 本機較新 | 「本機版本較新」，保留現有安裝 | 「解除安裝」 |
| 任一版本不明、格式無法比較，或安裝紀錄讀取失敗 | 「需核對版本」，不自動替換 | 「需核對版本」（開啟詳情） |

在 Windows 測試版中，全部五個 `v2.1.2` 目錄條目都會執行真實的分步安裝與解除安裝彈窗（從 Worker/R2 鏡像下載或沿用快取，隨後完成 SHA-256 校驗、備份、安裝／還原、讀回驗證、失敗重試以及互斥衝突提示）；在 macOS 上或面對未驗證版本時，操作僅說明狀態，不修改任何遊戲檔案。

## 詳情彈窗

依序顯示：詳細說明（連線條件、所需載入器、互斥關係）、支援遊戲版本、目錄版本、本機版本與狀態說明（如有）、清除快取按鈕（已快取時）、安裝包下載連結（允許鏡像時），以及帶外部連結圖示的作者首頁入口。

## 設定頁

設定頁由三塊面板組成：

- **介面語言**：三段式 `.segmented` 切換控制項（`简体中文` · `繁體中文` · `English`）。初次依系統語系選擇，使用者選擇保存在 `localStorage`。
- **遊戲目錄**：標題列旁在驗證通過時顯示精簡的 `v2.1.2` 版本標籤，下方以等寬字型只顯示已保存的遊戲根路徑（不顯示 `Machine Party_Windows` 等子目錄），右側對齊「選擇遊戲目錄」與「重新偵測」按鈕。重新偵測若找到 0 份或多份副本，會保留現有有效目錄；不再顯示冗餘的「重新校驗檔案」按鈕。
- **管理器與更新**：合併為單行，左側為帶底線的 `Machine Party 模組管理器` 連結（經 `open_project` 開啟 GitHub 倉庫），右側為版本號按鈕並在啟動時自動靜默檢查更新，有新版時顯示紅點 `.update-dot`。頂部不設更新橫幅按鈕；發現新版後每個版本號自動彈出一次非強制更新彈窗（若目前已有彈窗則順延排隊，點擊「稍後再說」或關閉彈窗後將版本號寫入 `localStorage`，也可隨時點擊設定頁版本號手動重開），顯示 `notes` 更新說明或預設提示，支援「更新並重新啟動」與百分比進度條。

## 首次啟動

找到唯一遊戲副本時直接載入；找到多份時彈窗列出候選路徑；找不到時提示選擇目錄或先瀏覽，可「稍後設定」。

## 規劃中

- 側邊欄底部的遊戲狀態列：綠點加「遊戲版本 v2.1.2」；未偵測到遊戲時改為警示色，點擊選擇目錄。
- 互斥模組的一鍵「切換」按鈕：確認彈窗說明將取代的模組，先備妥新套件再還原舊模組並安裝新模組。
