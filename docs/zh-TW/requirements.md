# 產品需求

[English](../en/requirements.md) · [简体中文](../zh-CN/requirements.md) · **繁體中文**

## 首頁與搜尋

首頁直接呈現團隊已驗證並發布的目錄。每個項目提供名稱、作者、用途、作者專案首頁、適用遊戲版本、可安裝版本、本機狀態與主要操作。上游有新版時，只有通過團隊驗證的版本可供安裝。

- 搜尋在本機比對已收錄的名稱、作者、簡介與維護者整理的繁簡中文、英文別名。清空搜尋即顯示完整目錄。無結果時顯示「找不到已收錄的模組」。
- 排序只取決於固定收錄序號。搜尋、更新、改名與 Stars 變化都維持相對順序。最新或最早收錄在前，待首頁定稿時決定。
- 產品不提供篩選、排行榜或 GitHub 全站搜尋。模組資料來自 GitHub，收錄、相容性與安裝版本由團隊決定。
- App、搜尋、安裝與卸載免費。模組詳情提供作者入口，玩家可選擇查看原始說明。

## 第一次開啟

找到唯一有效的 Steam 遊戲副本時直接顯示可用操作。找不到遊戲時仍可瀏覽；在安裝位置顯示「選擇遊戲目錄」。找到多份時顯示候選路徑供選擇。設定頁提供目前路徑、重新偵測與手動選擇，記住玩家有效的手動選擇。

## 一鍵管理

| 玩家動作或情境 | 可觀察的結果 |
| --- | --- |
| 點「安裝」 | App 下載指定版本、校驗、備份並安裝。顯示進度，驗證成功後顯示已安裝版本。 |
| 點「卸載」 | App 使用本機紀錄移除模組並驗證結果。保留其他模組需要的檔案、共用載入器及玩家原有資料。 |
| 點「切換」 | 明示將取代的互斥模組。先備妥新套件，再還原舊模式並安裝。顯示實際生效狀態。 |
| 遊戲執行中或資料不符 | 提示關閉遊戲重試，或顯示不相容的版本／未知修改。完成辨識前暫停寫入。 |
| 網路中斷或模組下架 | 可瀏覽與搜尋已快取的目錄，並離線卸載先前由 App 安裝的模組。首次離線啟動應提示目錄尚未下載。 |

## 首版驗收

1. Steam 裝在非系統磁碟仍能偵測；手動選擇在重啟後保留，原路徑失效才重新偵測。
2. 玩家只操作 App 即可安裝已驗證的 Overtime；從 Steam 進入遊戲看到對應版本並完成一局。
3. 斷網後點一次卸載，原版 PCK 的 SHA-256 與安裝前一致，可再次啟動原版。
4. 模擬下載失敗、寫入中斷與 Steam 更新。重新開啟後顯示實際狀態，避免舊備份覆蓋新版遊戲。
5. 搜尋命中別名時仍按收錄序號呈現。開啟作者首頁與安裝是兩個獨立操作。
6. 大陸玩家在無代理、無 App 快取且無法連 GitHub 時，能經正式 Worker 取得目錄。已同步過的玩家斷網後可搜尋快取；首次離線時提供重試與本機已安裝入口。按[三網驗收方案](catalog/delivery.md)分別驗證列表與套件下載。
