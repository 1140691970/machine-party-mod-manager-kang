# ADR-013 · 從簽章目錄安裝原生模組

[English](../../en/architecture/ADR-013-signed-native-installs.md) · [简体中文](../../zh-CN/architecture/ADR-013-signed-native-installs.md) · **繁體中文**

舊測試版能顯示新模組，安裝卻需要再發一版管理器。現在第一方新模組可經簽章目錄加入：核對作者倉庫、以 ID 記錄安裝及內建載入器適配規則。適配規則只允許變更套件內檔案清單。測試版接受測試頻道，正式版需已驗證條目。轉包模組沿用內建轉換規則。

首次安裝、更新與掃描使用同一份授權資料。管理器保存新 ID 的首份簽章說明，再次驗簽後可用於離線掃描及解除安裝。線上套件的安裝仍須符合目前授權。既有安裝紀錄及備份繼續適用。

在「已安裝」按「檢查模組更新」。有相容新版時會顯示「更新至」；點開可核對舊版、新版和遊戲位置。按「確認更新」後才開始下載。目錄測試涵蓋新 ID 與不相容適配規則，交易測試涵蓋更新及還原。
