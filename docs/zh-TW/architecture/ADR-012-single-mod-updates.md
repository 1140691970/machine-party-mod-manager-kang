# ADR-012 · 更新單一已安裝模組

[English](../../en/architecture/ADR-012-single-mod-updates.md) · [简体中文](../../zh-CN/architecture/ADR-012-single-mod-updates.md) · **繁體中文**

已安裝模組有較新的核准版本時，玩家可單獨更新該模組。管理器逐段比較數字版本號，Rust 後端以安裝交易識別遊戲副本和模組。

目錄部署流程會將 `machine-party-mod-catalog-v1\n` 加在完整 UTF-8 目錄前，再用發布金鑰簽署。只有完整目錄帶有簽章。對於管理器已認識的原生 MPML 模組，後端會核對簽章、模組 ID、作者倉庫、內建適配器設定、套件大小和 SHA-256。正式版只接受已驗證的版本，Windows 測試版也接受明確標為測試的模組版本。內建套件沿用既有授權。需要轉換的模組推出新版時，管理器須先內建對應的轉換規則。

先卸載再安裝可能移除共用載入器，或因下載失敗而失去舊版。單模組更新會在遊戲所在磁碟準備已驗證的新版、核對舊檔、記錄兩組指紋，再替換所選模組目錄。寫入新交易是提交點，中斷發生在提交前會還原舊版，提交後會保留已驗證的新版。若遊戲執行中或檔案出現未知變更，管理器會保留復原記錄供下次掃描處理。

發行包測試在同一份合成遊戲副本安裝滾筒嘉年華 v0.1.0 和 Lobby Bots v0.1.4，再將滾筒更新至 v0.1.1。測試核對失敗還原、重啟復原、共存模組的檔案與交易、共用載入器與 PCK 指紋，以及離線卸載。Windows Steam 遊戲內驗收仍待完成。
