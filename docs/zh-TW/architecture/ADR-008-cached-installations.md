# ADR-008 · 下載快取、啟動偵測與還原校驗

[English](../../en/architecture/ADR-008-cached-installations.md) · [简体中文](../../zh-CN/architecture/ADR-008-cached-installations.md) · **繁體中文**

重開管理器時，讀取 PCK 的延遲可能讓已安裝的模組暫時顯示為未安裝。殘留還原檔也可能被誤認為手動安裝。每個目錄版本獨立快取下載。Rust 從隨包目錄解析安裝參數，使用前重新校驗 ZIP，寫入前再次確認所選副本。

啟動先顯示已有紀錄，依相關檔案的識別、大小和修改時間重用顯示狀態。副本變更或手動重新檢查時才完整讀取一次 PCK。發現疑似手動安裝時，使用相符的快取套件執行上游唯讀狀態檢查；接管還需要在臨時副本試還原成功。原版 PCK 旁有未知還原檔時提示殘留。

新安裝保留經過校驗的完整備份。解除安裝完成需要原版 PCK 指紋相符，且本次建立的附屬檔已清除。啟動偵測保留備份，清除下載也保留各副本的還原資料。繼續讀取已有安裝紀錄、路徑及舊版差量交易。每次啟動計算完整雜湊會增加磁碟讀取，僅憑檔案屬性也不足以授權寫入。

Rust 測試涵蓋再次啟動、強制檢查、殘留檔案、外部修改和操作中斷。Windows 測試版仍需在玩家的 Steam 副本上驗證遊戲和離線還原。
