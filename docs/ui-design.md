# 介面設計規範

首版桌面端採暗黑工業風（貼近 Machine Party 遊戲氛圍），介面語系為**簡體中文**。本文件定義首頁佈局、卡片資訊層級與互動狀態，作為後續切版與實作依據。

## 整體佈局與視覺基調

- **視窗與色彩**：Windows 暗色無邊框／自訂標題列（左側顯示 `Machine Party 模组管理器`，右側為視窗控制鈕）。背景採深炭灰階層（側邊欄深於主內容區，卡片採微弱邊框區隔），主要操作按鈕採暖米白（`#EDE8D0` 風格）搭配深色文字，次要／危險操作採深色外框按鈕。
- **左側導覽欄**：
  - 頂部品牌識別：`MACHINE PARTY` 與副標 `模组管理器`。
  - 主導覽項目：`模组目录`（預設啟用）、`已安装`。
  - 底部狀態與設定（採無框單行文字，不放大型狀態卡片）：
    - 遊戲版本狀態：綠點搭配 `游戏版本 v2.1.2`（未偵測到遊戲時改為警示色並提示點擊選擇目錄）。
    - 設定入口：`设置`（管理 Steam 目錄、手動選擇與本機備份資訊）。

## 首頁與搜尋列

- **標題區**：左側為主標題 `模组目录` 與副標 `团队已验证并发布的模组`；右側為搜尋框，提示文字為 `搜索模组、作者或关键字`。
- **搜尋行為**：在本機比對名稱、作者、簡介與繁簡中文／英文別名；清空即恢復完整目錄；無結果時顯示 `找不到已收录的模组`。

## 模組卡片結構

採等高三欄卡片網格，保持資訊克制、不在卡片上顯示「適用遊戲版本」等額外標籤（相容性改於安裝或切換時檢查並提示）：

1. **封面縮圖區（16:9）**
   - 保持畫面乾淨，不在圖片上疊加模組名稱。
   - 僅於右上角顯示低調狀態標籤：
     - 已安裝：`已安装 v1.7`
     - 存在依賴／互斥：`需 MPML · 与 Overtime 互斥`
     - 尚未開放安裝：`待验证`
2. **標題與簡介區**
   - 標題列：模組名稱搭配低調灰字版本號（如 `Overtime v1.7`、`MachineParty+ v2.1.0`）；未發布可安裝版本者不顯示版本號（如 `Broadcast 8P Freecam`）。
   - 簡介：精簡說明核心用途與安裝／聯機前提（如 `支持最多 8 人在线或本地同玩（直接改包）`、`公开房间、语音与文字聊天（语音需要双方安装）`）。
3. **底部操作區**
   - 上排：左側為作者專案外連入口（如 `DarkJadeStone ↗`），右側為 `详情` 入口（開啟詳情彈窗／抽屜，承載完整聯機要求、依賴與還原說明）。
   - 下排全寬主要操作：
     - 未安裝且相容：`安装`（暖米白主按鈕）
     - 已安裝：`卸载`（深色外框按鈕）
     - 與目前生效模組互斥：`切换`（暖米白主按鈕，點擊後彈窗明示將取代的模組並先備妥新套件再還原舊模組）
     - 待驗證項目：純文字 `尚待实测`（不可點擊）

## 互動彈窗與狀態提示

- **安裝／切換確認與相容性提示**：點擊 `安装` 或 `切换` 時檢查遊戲執行狀態、遊戲版本指紋與互斥關係；若版本不相容、遊戲執行中或存在未知修改，於此流程中斷並明確提示下一步。
- **模組詳情（`详情`）**：獨立顯示原版多人能力差異、模組聯機條件（例如語音需雙方安裝）、所需載入器（如 MPML）與上游授權資訊。

## 三語與版本狀態（取代上方相應的卡片規格）

介面支援簡中、繁中及英文。初次依系統語系選擇，設定頁可覆寫並保留選擇。左欄導覽列高至少 44px，項目間距 6px。封面左上顯示目錄版本，右上顯示狀態。點標題開啟詳情，作者入口移入詳情，卡片底部保留全寬安裝、更新或解除安裝按鈕。已安裝項目另列本機與目錄版本。

目錄目前使用隨客戶端發布的候選資料；版本標籤本身不代表通過驗證。用戶端從設定目錄的 installations.json 讀取管理器紀錄，第一層鍵是所選遊戲路徑，第二層鍵是模組的作者/倉庫名，值是已安裝版本。沒有紀錄時不推定玩家手動安裝的版本。

| 本機與目錄比較 | 卡片與操作 |
| --- | --- |
| 數值版本相同 | 顯示「与目录版本一致」 |
| 本機較舊、新版待驗證 | 顯示「新版待验证」，保留現有安裝 |
| 本機較舊、新版已驗證 | 顯示「有更新」；待安裝引擎接入後提供「更新到 vX」 |
| 本機較新 | 顯示「本机版本较新」，保留現有安裝 |
| 任一版本不明或格式無法比較 | 顯示「需核对版本」，不自動替換 |

更新執行流程待接入。在確認視窗並列目前版本與目標版本，檢查遊戲相容性、執行狀態與備份後，依序顯示下載、校驗、套用、驗證。最終成功才寫入新版安裝紀錄。失敗時重新辨識磁碟狀態，再顯示仍生效的版本或修復入口。
